調整用素材（パターンA・B共通）

property-01〜06は、サイトの物件１〜６に対応します。
各フォルダーには、掲載中のパース5枚（JPG）と間取り1枚（PDF）があります。
写真の内容とファイル名の対応はphoto-index.csvに記載しました。

JPGはサイトに埋め込まれた画像から、縦横比とピクセル数を保って書き出しています。新たな描き直しや拡大補間は行っていません。
PDFは図面の線・文字などのベクター情報を保持して、物件ごとに分割しました。Illustrator等で開いて調整できます。元データでアウトライン化されている文字は、文字列として編集できない場合があります。
物件２は修正版の間取りを使用しています。
物件３と４は元のPDFのページ順と異なるため、サイトの物件番号に合わせて並べ替えています。

物件１：西日にほどける部屋
物件２：街の余韻をほどく窓辺
物件３：木の窓辺に残る時間
物件４：光を受けとめる白い部屋
物件５：床の高さに居場所をつくる
物件６：青いタイルとやわらかな光
