# パターンB：学生の居住も想定した賃貸版

## パターンの区別
既存の売買版をパターンA、このZIPをパターンBとします。Aの成果物は変更していません。Bの更新は今後このファイルへ反映します。

## アップロード
ZIP直下の22個のHTMLを同じ階層に配置してください。入口はindex.htmlです。画像・間取り・CSS・JavaScriptはHTMLへ埋め込んでいるので追加の画像アップロードは不要です。Aと同時公開する場合は、BのHTMLを別の公開フォルダー（例：pattern-b/）へ置いてください。Aのファイルへ上書きすると、その公開先はBになります。タブ内の参加番号保存はB専用に分離しました。

## 実験構成
番号を6で割った余りでsummary-0〜5へ進みます。基準2件（物件1・2）、文章あり2件、文章なし2件の割り当て、物件1〜6の固定順、最終ページの再閲覧リンクはAを引き継ぎます。基準は月額賃料を表示、その他は「＊＊＊＊円／月」。管理費は全物件で表示します。タイトルは物件番号、情緒的な見出しは文章あり本文のみ。氏名は収集しません。

## 物件設定
全6件を学生相談可・単身入居可の賃貸マンションへ変更しました。所在地は実在する町名・丁目単位です。特定の実在建物・部屋の募集を表すものではありません。駅徒歩分数、賃料、費用、設備、募集条件は研究用の架空設定です。間取り面積と修正済みパースはAを維持し、寝室と作業・食事の場を分けたい学生の居住も想定しています。一般的な学生向けワンルームへの変更はしていません。住所の確認先はsources.mdを参照してください。pattern-b-research-data.jsonには研究者用の設定値を記載しています（公開用HTMLの隠し賃料は伏せたままです）。

## アンケート
最終ページは従来のGoogleフォームのリンクを維持しています。Googleフォーム自体は変更していません。Bで調査する前に、購入価格の設問を「この物件の月額賃料はいくらが妥当だと思いますか。管理費を含めず、円単位で数字のみ入力してください。」など賃料の設問へ変更し、必要ならB専用フォームURLへ差し替えてください。基準の賃料は物件1＝82,000円／月、物件2＝68,000円／月です。フォームの対象番号・概要・再閲覧URLもBの公開先へ変更してください。
